# 🧮 Smart Calculator - All-in-One Web Application

A sleek, fast, offline-first **Smart Calculator** web application featuring standard arithmetic, collapsible scientific functions, calculation history, memory controls (`MC`, `MR`, `M+`, `M-`, `MS`), and 5 customizable themes.

## 🌟 Key Features

- **Standard & Scientific Dual Mode**: Easily toggle between basic arithmetic and advanced trigonometric/logarithmic scientific functions.
- **5 Dynamic Color Themes**: Dark Glass, Light Mode, Cyberpunk Neon, Sunset Gold, and Emerald Slate.
- **Memory Toolbar**: Full memory state management (`MC`, `MR`, `M+`, `M-`, `MS`).
- **Calculation History**: Automatic history drawer logging, favoriting, and CSV export.
- **Web Audio & Haptics**: Realistic tactile button click sounds and mobile vibration feedback.
- **Keyboard Shortcuts**: Native physical keyboard input support.

## 🚀 Quick Start

Simply open `index.html` in any web browser, or run a local HTTP server:

```bash
# Served locally on http://localhost:8080
```

## 🛠️ Built With

- **HTML5** & **Vanilla CSS3** (Custom Properties, Glassmorphism, HSL color tokens)
- **Modern ES6+ JavaScript** (Zero dependencies)
